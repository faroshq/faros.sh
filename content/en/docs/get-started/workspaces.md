title: "Understand organizations, workspaces, and providers"
description: "Know where you are working before creating resources."
weight: 4
doc_type: "Concept"
---

An organization groups your team. A workspace holds resources and enabled capabilities. A provider adds a capability such as App Studio or Edges.

Select the workspace in the console before beginning a tutorial. If a resource or provider seems to be missing, check that selection first. Different workspaces can have different providers and permissions.

Read [the shared concepts](/docs/concepts/) for identity and runtime details, or [Administration](/docs/administration/) to create and manage team access.
