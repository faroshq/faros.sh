MCP

Already logged in? Select your workspace, then print its MCP setup snippets.

kubectl faros use
kubectl faros mcp url --mcpserver-name default

Use the printed configuration in your MCP client. It includes credentials; keep it private and review the server’s scope.

CLI

Install the CLI, then replace YOUR-HUB with your hub’s address.

kubectl faros --help
kubectl faros login --hub-url https://YOUR-HUB
kubectl faros use

Login updates your kubeconfig. Use the authentication guide if your hub requires a static token.
