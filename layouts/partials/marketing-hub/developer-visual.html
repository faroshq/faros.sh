Select a workspace, list its connected edges, or get an MCP endpoint for your agent. Try the commands below with kubectl-faros.

Select a workspace

$ kubectl faros use --org acme --workspace platform
What this doesacme / platformselected organization and workspace

Selects the organization and workspace without a prompt. Subsequent commands use this workspace.

Get the workspace MCP endpoint

$ kubectl faros mcp url --mcpserver-name default
What this doesWorkspace MCP endpointUse this URL in your MCP client

Prints the workspace MCP URL. The CLI also supports a separate endpoint for each connected Kubernetes edge.
