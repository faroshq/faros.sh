One workspace.
Several ways in.

Use the CLI to choose a workspace, reach an edge, or hand an agent the endpoint it needs. The same boundaries stay visible as the interface changes.

faros / workspace

Select a workspace

$ kubectl faros use --org acme --workspace platform
explained resultacme / platformselected organization and workspace

The scripted form selects the organization and workspace without prompts, so following commands target that workspace.

Give an agent its endpoint

$ kubectl faros mcp url --mcpserver-name default
explained resultworkspace aggregateendpoint → client setup

The command prints the MCP endpoint for the selected workspace. Use the per-edge form for a Kubernetes edge.
